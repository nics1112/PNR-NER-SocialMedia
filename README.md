# PNR-NER-SocialMedia
Comparative evaluation of spaCy, Stanza, and GLiNER for person name recognition in informal, social media-like texts.

The zip folder contains the following files:

- The file social_sentences_final.csv is the dataset, consisting of two columns: noisy_sentence and ground_truth.

- The files spacy.ipynb, stanza.ipynb and gliner.ipynb contain the code that loads the different models and the dataset, performs NER on the sentences and displays the different metrics for each of the three tools.

- The file plots.ipynb contains the code to display the images of the comparison of the three tools on precision, recall and f1-score.

- The files precision.png, recall.png and f1.png represent the images generated by the code described above.

This project uses the following open-source NLP tools for named entity recognition (NER):

- **spaCy**:
  
  https://spacy.io  
 

- **Stanza**  
  https://stanfordnlp.github.io/stanza/  
 

- **GLiNER**  
  https://github.com/urchade/GLiNER
